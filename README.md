## مبنى الصفحة

صفحة وحدة قصيرة، هدفها إنه الزبون يتواصل معنا:
1. **Hero**: اللوجو، جملة وحدة مين إحنا، وأزرار: הצעת מחיר / וואטסאפ / התקשרו.
2. **מה אנחנו עושים**: 4 كروت قصار (אתרים, חנויות, מיתוג, פרסום).
3. **צרו קשר**: الفورم، وتحته أزرار تواصل مباشر.

على التلفون في شريط تحت ثابت (השאירו פרטים + واتساب)، وبيختفي لما يوصل الزبون للفورم.

## كيف بيشتغل الفورم

الزبون بيعبّي: اسم (إجباري)، تلفون **أو** ميل (واحد منهم بيكفي)، وبشكل اختياري نوع الخدمة (أزرار) ورسالة.

- التفاصيل بتنبعث **عالميل `nexora131415@gmail.com`** عن طريق [Web3Forms](https://web3forms.com) (حساب Google تبع nexora). الإيميل بيوصل خلال ثواني.
- الموضوع: `פנייה חדשה מהאתר — <اسم الزبون>`، والمرسل: "Nexora — אתר".
- إذا الزبون كتب ميل، بتكبس **Reply** والرد بيروح لإله مباشرة.
- إذا الإرسال فشل، الزبون بيشوف رسالة خطأ (مش "נשלח" عالفاضي).
- honeypot ضد البوتات (حقل مخفي `company_website`).
- الخطة المجانية: 250 פנייה بالشهر.

المفتاح موجود بآخر `index.html` تحت `CFG.web3formsKey`. هو مش كلمة سر، عادي يكون مكشوف بالكود.
